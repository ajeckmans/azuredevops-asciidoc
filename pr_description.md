💡 What: Added `Tooltip` wrappers around the "Copy link to comment" and "Resolve thread" icon-only buttons in `DiscussionThread.tsx`.
🎯 Why: Icon-only buttons lack visible text, which can make their purpose unclear to users relying on visual cues. Adding tooltips provides immediate, on-hover context about the button's action.
📸 Before/After: Screenshots included in the PR comments.
♿ Accessibility: The `Tooltip` component improves usability by providing visual labels for icon-only buttons.
